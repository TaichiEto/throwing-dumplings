# 🥟 餃子投げ検定試験 (Gyoza Throwing Master)

中華料理屋さんの店員に向かって餃子を投げつけ、その腕前を競うアクションゲームです。
制限時間内にハイスコアを目指し、「餃子神」の称号を手にしましょう！

## 📋 ゲーム概要
主人公は伝説の名店「投気楼」に現れた一人の客——**餃子投男**。
彼は提供された餃子を食べずに、投げ返すのだ。店員たちはそれを華麗にキャッチする。
客が投げ、店員が受ける、奇妙で美しい検定試験。その裏で店を狙う「謎の存在」との戦いを描くストーリーも搭載！

**すべてのモードは「スマホの親指ひとつ」で遊べます。** タップだけで発射・ジャンプ・玉打ちが完結！

- **操作方法**:
    - 画面を **クリック / タップ** するだけ（発射 / ジャンプ / 玉発射）
    - ボス戦の回避はボタンまたは **スペースキー**！
- **難易度選択**: 「見習い」「職人」「鬼」の3段階。制限時間・敵の速さ・ボスの強さが変化します。

## 🎮 ストーリーモード（メイン）
**全7ステージ+最終ボスを一気に冒険！** ステージ間には物語の幕間が入り、スコアは累計されます。
やられても「そのステージからやり直し」できるので安心。クリア時は累計スコアで**総合段位**が認定されます。

1. **STAGE 1『投気楼の夜』** — 腕慣らしの餃子投げ（30秒）
2. **STAGE 2『あとデカイのは客か』** — 1.5倍のデカ客に当てるな！
3. **STAGE 3『餃子大冒険』** — マリオ風アクションで謎の存在を追え
4. **STAGE 4『音速餃子』** — ソニック風ハイスピードチェイス
5. **STAGE 5『悪人の集まる所』** — 悪人退治&中ボス戦
6. **STAGE 6『餃子空中戦』** — シューティング！スライド移動&自動連射で25体撃墜
7. **STAGE 7『歓楽街の大勝負』** — パチンコのボーナスステージ
8. **FINAL『決戦！謎の存在』** — すべてを懸けたボスバトル

## 🕹️ フリープレイ（1ステージだけ遊ぶ）
| モード | 内容 |
|---|---|
| 🥟 **検定モード** | 王道の餃子投げ。一定スコアで「謎の存在」とのボス戦へ |
| 🍽️ **あとデカイのは客か** | お客様が通常の**1.5倍**の大きさで大量出現。当てると大ペナルティ！ |
| 🦹 **悪人の集まる所** | 悪人だらけの巣窟で餃子退治。スコアを稼ぐと**中ボス悪人**が襲来！一般人は巻き込むな |
| 🍄 **餃子大冒険** | マリオ風横スクロールアクション。タップでジャンプ（2段ジャンプ可）、餃子を集めて敵を踏んでゴールへ |
| 💨 **音速餃子** | ソニック風ハイスピードステージ。起伏を駆け抜け、バネで跳び、爆弾を踏むと餃子が散らばる！ |
| 🎰 **大当たり餃子玉** | パチンコ風。左右に揺れる照準をタップで止めて玉を放ち、中央の**大当たり**ポケットで確変突入！ |
| 🛸 **餃子シューティング** | 縦スクロールSTG。指をスライドして移動、餃子は自動連射。カレー弾🍛をかわして敵を撃墜せよ |
- **検定システム**:
    - 命中数に応じてスコアが加算されます。
    - ゲーム終了時、スコアに応じて「5級」から「銀河餃子大帝」までの段位が認定されます。
    - ハイスコアは自動保存され、最大コンボ・命中率も記録されます。
- **難易度上昇**: 時間が経つにつれて店員さんの動きが速くなり、人数も増えていきます。

### 🎁 パワーアップ（画面を横切る泡を撃って取得）
- ⏰ **時間+5秒** / 🔥 **三連発射** / 🥟 **巨大餃子** / ⭐ **フィーバー（得点2倍）**

### 🔥 コンボ＆フィーバー
連続ヒットでコンボが伸び、得点倍率が最大4倍まで上昇。
15コンボ到達でフィーバーモード突入、画面が黄金に輝きます。

### 👹 ボス戦
一定スコアに到達すると「謎の存在」が襲来！ストーリーカットインの後、決戦が始まります。
HPが減ると**激怒モード**に突入し、攻撃が激しくなるので回避のタイミングに注意。

### 🎵 サウンド
WebAudioによるBGM（通常戦・ボス戦で曲が変化）と効果音を搭載。右下のボタンでミュートできます。
