中華料理屋さんの店員に向かって餃子を投げつけ、その腕前を競うアクションゲームです。
制限時間内にハイスコアを目指し、「餃子神」の称号を手にしましょう！

## 📋 ゲーム概要
主人公「餃子投男」を操作し、動き回る店員さんに餃子を提供する（投げつける）ゲームです。
伝説の名店「投気楼」を舞台に、店を狙う「謎の存在」との戦いを描くストーリーも搭載！

- **操作方法**:
    - 画面上の店員さんを **クリック / タップ** して発射！
    - ボス戦の回避はボタンまたは **スペースキー**！
- **難易度選択**: 「見習い」「職人」「鬼」の3段階。制限時間・敵の速さ・ボスの強さが変化します。
- **検定システム**:
    - 命中数に応じてスコアが加算されます。
    - ゲーム終了時、スコアに応じて「5級」から「銀河餃子大帝」までの段位が認定されます。
    - ハイスコアは自動保存され、最大コンボ・命中率も記録されます。
- **難易度上昇**: 時間が経つにつれて店員さんの動きが速くなり、人数も増えていきます。

### 👥 店員・お客様たち
| キャラ | 得点 | 特徴 |
|---|---|---|
| 👨‍🍳 店員さん | 1皿 | ふつうの動き |
| 🐱 猫店員 | 2皿 | すばしっこい |
| 🥷 忍者店員 | 3皿 | かなり速い |
| 🤴 王様店員 | 5皿 | 激レア＆高速。金のオーラが目印 |
| 😡 お客様 | **−5皿** | 当てるとコンボが途切れる。投げるな危険！ |

### 🎁 パワーアップ（画面を横切る泡を撃って取得）
- ⏰ **時間+5秒** / 🔥 **三連発射** / 🥟 **巨大餃子** / ⭐ **フィーバー（得点2倍）**

### 🔥 コンボ＆フィーバー
連続ヒットでコンボが伸び、得点倍率が最大4倍まで上昇。
15コンボ到達でフィーバーモード突入、画面が黄金に輝きます。

### 👹 ボス戦
一定スコアに到達すると「謎の存在」が襲来！ストーリーカットインの後、決戦が始まります。
HPが減ると**激怒モード**に突入し、攻撃が激しくなるので回避のタイミングに注意。

### 🎵 サウンド
WebAudioによるBGM（通常戦・ボス戦で曲が変化）と効果音を搭載。右下のボタンでミュートできます。
